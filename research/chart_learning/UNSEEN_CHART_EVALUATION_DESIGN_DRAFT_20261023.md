# v83 — 독립 판단 검증 절차 및 준비도 제안

2026-10-23 / 기존 P028 초안 구체화 / **DESIGN ONLY · PROPOSED FOR RATIFICATION · NOT EXECUTED**.

현재 판정: **문서상 절차 구체화 완료 / 실행 준비 미완료**. 평가 승인, 판정 담당자, 검증된 입력 묶음, 모델·가정·기준의 최종 동결이 남았다. 종목·기간 선정0, 가격 수집0, 평가 답변0. 아래 숫자는 연구진의 정책 제안이지 원본에서 검증된 매매 규칙·승률·숙련도 기준이 아니다. 하단 v82 원문은 당시 이력으로 그대로 보존한다. 새 P029·교훈·매매 규칙은 만들지 않는다.

## 1. 무엇을 검증하고 무엇을 주장할 수 있는가

첫 평가의 대상은 주어진 일봉·주봉(필요한 월봉 포함)에서 **근거가 추적되는 분석·조건부 거래 선택·위험 판단을 재현하는 능력**이다. 중요한 가격은 이후 반등한 가격이나 전문가와 숫자가 같은 가격으로 정의하지 않는다. 실제 거래·수익·종목 발굴 능력은 이 평가로 확인되지 않는다. SOURCE REVIEWED와 METHOD SYNTHESIZED의 축적을 TRANSFER VALIDATED로 자동 승격하지 않는다. 통과해도 해당 입력·국면·판정 범위만 제한적으로 보고하고 M-01~M-07 및 경제성은 별도 판정한다.

핵심 변경은 ‘정답 가격과 일치하는가’에서 ‘관찰 가능한 근거로 선택했고, 다른 합리적 기준에도 판단이 견디며, 실패 조건이 연결되는가’로 판정을 구체화한 것이다. 이는 평가 설계의 발전이며 분석능력 향상이 입증됐다는 뜻이 아니다.

## 2. 입력 묶음 계약 — 실제 구성은 승인 이후

각 packet에는 불변 case_id/family_id, 출처·접근 권한, 원시 자료/이미지 SHA256, cutoff와 시간대·세션·수정가격 정책, 완료 봉 ID, 진행 봉의 포함 여부, 원시 OHLCV prefix, 그 prefix로만 집계한 일/주/월봉, 지표 산식·입력 범위를 기록한다. 표준 화면의 확대 범위·로그/선형 축·표시 봉 수·제공 지표는 두 방법에 같게 한다. 정확한 피벗 가격을 채점하려면 이미지뿐 아니라 재계산 가능한 원시 행이 필요하다. 이미지밖에 없으면 수치 재현 항목을 검증했다고 처리하지 않는다.

월봉 미제공·주봉 진행 중·거래량 출처 불명 등은 입력에 명시한다. 부족한 상위 정보가 실제 판단을 막는 packet은 적격성 심사에서 보류하며, 숨은 필수 정보를 모델이 추측하도록 만들지 않는다. 계좌 규모·기존 노출·가정 손실 한도·평가 목적의 관찰/재검토 주기는 별도 scenario 계약으로 두 방법에 동일 제공한다. 이번에는 계좌 수치나 기간을 만들지 않는다. 이 값 미동결 상태에서 자본 위험 비교는 실행 불가다.

전체 기간으로 계산한 수정치·프로파일·피벗 표시가 cutoff 이후 정보를 사용하는지 감사한다. 조정가격은 cutoff 당시 알 수 있었던 기업행사만 적용하거나 당시 재현 불능을 표시한다. 피벗 발생 봉과 확인 가능 봉은 별도 필드다. 완성되지 않은 주/월봉을 완성 봉으로 렌더링하지 않는다. RSI는 같은 시간축의 완료 피벗과 대응 값으로, CVD는 공격적 체결량·anchor/reset 근거가 있을 때만 해석하게 한다. SRC-TERM-001 미확정 산식을 입력/정답에 넣지 않는다.

## 3. 노출·중복·미래정보 차단

자료 관리자는 분석자와 분리하고 cutoff 이하만 담긴 입력을 준비한다. 후속 결과 저장소는 별도 권한으로 분리한다. 이번 1차 과정 판정은 후속 가격을 열 필요가 없다. 사용자 승인도 없는 S02 잠긴 결과는 어떤 단계에서도 쓰지 않는다.

출처 목록/기존 연구 사례/전문가5가격계획과 대조하고 종목·겹치는 기간·동일 사건·다중 시간축·크롭·재게시를 family로 묶는다. 한 issuer는 주 표본에서 한 사건만 허용하고, 관련 시장 충격은 별도 cluster_id로 기록한다. 익명화·좌우 크롭만으로 미노출을 보장하지 못한다. 분석자에게 노출 신고 경로를 주고 알아본 packet은 답변 전에 격리한다. 모델 사전학습에 포함됐는지는 완전 확인할 수 없으므로 ‘기존 연구 corpus와 대조한 미노출’과 ‘모델 학습 이력 불명’을 함께 표시한다. 절대적 미학습 보장은 주장하지 않는다.

선택 알고리즘·모집 틀·포함/제외·국면 분류·표본 난수 seed·packet 순서를 출력 전에 동결한다. 미래 승자/실패자를 골라 넣은 도전군은 별도 분리하고 주 표본 성과와 합치지 않는다. 익숙한 사례를 사용한 판정 연습도 holdout에서 제외한다. 평가 중 방법을 고치면 버전 변경으로 종료하고 같은 사례 재시험을 새 독립 증거로 세지 않는다.

## 4. 중요한 가격의 판정 — 복수 해석을 허용하되 무제한 허용하지 않음

독립 판정자2인이 모델 답변과 후속 결과를 보지 않고 각 packet의 기준표를 작성한다. 서로 다른 의견은 제3 판정자가 같은 cutoff만 보고 조정한다. 누구의 선이 유명한지는 근거가 아니다. 기준표는 반드시 source bar ID와 재현 절차를 포함하고, 두 판정자의 원 의견·조정 이유도 보존한다. 전문가 정답을 모사하는 시험이므로 객관적이라고 주장하지 않고, 판정의 합의도와 한계를 공개한다.

|필수 근거|적격 판정|부적격/미확인|
|---|---|---|
|발생 근거|완료된 고저점·실체·사건봉 또는 독립 반응군의 봉 ID, 당시 확인 가능 시점|선이 그어져 있다는 사실만 인용; 아직 발생하지 않은 피벗|
|역할|관측된 거절/수용과 현재 후보 역할을 구분; 일봉 가설과 주봉 구조 분리|가격이 선 위라는 이유로 지지 확정|
|선택 중요성|가까운 상단 부담·하단 실패 경로 등 실제 판단을 바꾸는 이유|모든 선을 무순위로 나열; 상단 위험 생략|
|재현성|수평 가격/구간의 실제 봉 근거; 추세선은 두 anchor ID·발생/확인시각·line(t)의 시간축|복제 평행선을 독립 증거로 합산; 미확인 공식·기울기 창작|
|민감도|합리적인 몸통/꼬리 또는 대안 피벗에서 유지/변경되는 판단|대안으로 결론이 바뀌는데 확실하다고 단정|

기준표의 허용 단위는 단일 정답 숫자 대신 **anchor family + 가격 역할 + 시점**이다. 같은 사건의 꼬리/종가가 각각 합리적이면 각 범위와 역할을 미리 기재한다. 구간 끝점도 관측 봉에서 추적되어야 한다. 차트 전체를 덮는 구간·임의 % 허용폭·출력 후 넓힌 정답 범위는 금지한다. 수평선과 시간에 따라 변하는 line(t)는 가격이 우연히 같아도 같은 기준으로 채점하지 않는다.

모델이 기준표 밖의 새로운 합리적 선을 제안하면 DISPUTED로 남기고 방법/후속 결과를 가린 상태에서 검토한다. 주 분석에서는 해당 항목을 성공으로 세지 않고 정해진 전체 분모에 남긴다. 이는 오답 확정과 다르다. 이견 건수와 ‘모두 적격일 경우’ 상한을 별도로 보고한다. 수용된 새 family는 부차적 해석으로 공개하고 다음 새 표본의 rubric 개정에만 반영한다. 이번 답변을 본 뒤 주 합격 판정을 유리하게 고치지 않는다.

## 5. 필수 출력 — 세 판단과 한 정보시점

|출력|필수 내용|충분한 답변의 최소 조건|
|---|---|---|
|정보 계약|cutoff·완료/진행 봉·부족한 정보·노출 신고|확인하지 못한 정보나 가격을 꾸미지 않음|
|분석 판단 A|상위 구조, 우선순위 가격구간과 봉 근거/역할, 대안 anchor, 가장 강한 반대 해석|중요 위험을 빠뜨리지 않고 선택을 재현 가능하게 설명|
|거래 판단 T|대기/조건부 고정 지정가 후보/지지 확인 후 후보/거절 중 선택, 발동·취소·재검토 조건|현재 아는 것과 나중 확인할 것을 분리; 미체결·추격 대가 인정|
|위험 판단 R|진입 가설 실패, 상위 구조 실패, 자본 제약 각각; 노출 축소 조건|낮은 지지로 실패한 진입을 연명하지 않고 새 가설에도 손실 장부 연속 유지|

가격을 산출할 근거가 없으면 특정 매수가를 강요하지 않는다. 다만 입력이 충분한데 일반적인 ‘더 기다리자’만 쓰는 것은 거래 판단의 완성이 아니다. 추가매수는 기존 포지션 scenario가 실제 제공된 경우에만 판단하며 평단 하락과 총 손실 노출 증가를 함께 설명한다. 구조가 유지돼도 자본 한도로 끝내야 하는 상황을 허용한다. 주봉이 유지된다는 이유로 장중 실패를 지우거나 장중 약세만으로 주봉 붕괴를 확정하면 모순이다.

## 6. 채점·중대 오류·회피 판정

A/T/R 각각 2=근거 추적 가능·필수 조건 충족, 1=미완성/이견/조건 미명시, 0=관측·시점·위험 계약과 모순으로 채점한다. 원문 인용 위치와 봉 ID를 근거로 점수를 남긴다. 입력 자체의 부족을 정확히 지적하고 가능한 조건을 명시하면 2점일 수 있다. 핵심 항목을 모르겠다고 회피하면 자동 2점이 아니다. **case pass는 A=T=R=2, 미해결 이견 및 중대 오류0**이다. 평균점수만 높아 위험 실패가 가려지지 않게 영역별 결과도 공개한다.

중대 오류는 별도 C코드: C1 미래정보 사용/미완료 봉 확정; C2 봉·산식·체결·CVD 근거 창작; C3 나중 지지 확인을 이전 지정가의 당시 근거로 사용; C4 실패 후 선·시간축·가설 변경 은폐; C5 새 가설로 손실/위험예산 초기화; C6 미체결을 보유·수익으로 계산. 단순 누락·합리적 이견은 중대 오류와 구별한다. 모델이 몰랐던 입력 오염은 curator 결함으로 쌍 전체 격리하고 모델 오류로 전가하지 않는다.

거래 판정 기준표에는 하나의 매수 명령 대신 cutoff 근거상 허용되는 행동 집합과 ‘조건부 후보를 식별할 수 있는가’를 기재한다. 다음 세 집합을 답변 전에 확정한다: (a)위험계약 안에서 적어도 하나의 조건부 후보가 설명 가능한 사례, (b)거절/정보 부족이 필요한 사례, (c)양쪽이 합리적인 경계 사례. 경계 사례를 억지로 정답 매수/거절로 만들지 않는다.

(a)에서 이유 없는 일괄 거절/일괄 대기는 기회 누락으로 T<2; (b)에서 근거 없는 진입 후보는 T<2, 위험 창작 시 중대 오류도 검토한다. (c)에서는 행동보다 논증·취소·위험 일관성을 채점한다. 후보 식별률, 부적격 진입 제안률, 근거 없는 회피율을 사전 집합별 분모로 공개한다. 미래 수익 종목을 놓쳤다는 이유로 회피를 오답 처리하지 않는다. 모든 최종 선택이 대기여도 합리적 조건부 기회를 구별했다면 그 부분은 인정하되 실제 거래 선택/체결/경제성을 검증했다고 말하지 않는다.

판정자 calibration은 기존 노출 자료에서만 진행하고 holdout과 분리한다. 기준 사례의 필수 출력·중대 오류 구분에서 미해결 이견이 남으면 rubric을 수정·동결한 뒤 시작한다. 실제 채점에서는 독립 원점수·항목별 일치율·조정 건수·최종 근거를 보존한다. 같은 분석 GPT의 자기 채점만으로 독립 판정 완료를 주장하지 않는다.

## 7. v81/v82 공정 비교

기준방법은 v81 `57a9656b99052fe3bd57fc717b248383056bdadf`, 후보는 v82 `2af74fba7c78410d888127434da818d2243039ca`에 고정한다. 이 v83 문서는 비교 평가 프로토콜이며 후보 방법을 몰래 v83으로 바꾸지 않는다. 시작 전 사용자 별도 승인,미노출/출처 적격 자료,동일 cutoff·완료 상태 확인,기준/후보 버전 고정,평가기준·판정자·정보 접근 분리,중복/유출 점검,원본과 답변의 불변 기록이 필요하다. 거래 위험 판단을 평가하려면 가정 예산의 기준시점·갭/비용 가정·기존 노출 제공 범위도 사전에 정해야 한다.

표본 수·시장 국면 구성·정량 합격 기준·경제 평가기간/비용·유출 감사 담당은 **아직 미정**이다. 임의 승률이나 수익 기준을 추가하지 않는다. 이 조건을 구체화하기 전 전이 검증 시작/통과를 주장하지 않는다. 원본 미검증 용어는 정량 규칙에서 제외하거나 자료 부족 판정을 허용하며 SRC-TERM-001을 우회하지 않는다.

이 초안에는 데이터 수집·스캔·실험 실행·성과 공개를 시작하는 명령이나 활성화 설정이 없다. 설계의 보존만 완료한다.
