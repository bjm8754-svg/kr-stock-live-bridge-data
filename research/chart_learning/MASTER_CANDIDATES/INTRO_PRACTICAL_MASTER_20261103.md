# 실전 MASTER 통합 후보 — 입문편 이후

2026-11-03. **CANDIDATE ONLY / NOT CANONICAL / NOT TRANSFER OR PROFIT VALIDATED.** 기존 MASTER와 시험v86 불변. 기존 스캐너를 새로 만들지 않는다. 스캐너의 후보를 독립 평가하여 향후 실제 성과 검증으로 연결하는 짧은 판단 절차다. S02·스캔·주문 중단은 해제하지 않는다.

## 판단 절차

1. **지금 무엇을 아는가.** 종목·거래상품·통화·자료시각·마지막 완료봉을 확인한다. 오래된 snapshot, 미완성 주/월봉, 실제값/추정값, 없는 장중 정보를 표시한다. 부족한 자료를 상상으로 채우지 않는다. 해당 판단에 필수인 자료만 추가 확인 대상으로 둔다.
2. **왜 이 후보인가.** 기계 family/등급에서 출발하되 실제 가격 구조로 매수 가설을 한 문장으로 쓴다. 범위 반등인지, 회복인지, 상승 지속인지 정한다. 지지·가까운 공급·상위 구조의 각 선에 원천 봉/시간축/산식/첫 식별시각을 붙인다. 기계밀도·boxClose를 저자의 메인선으로 부르지 않는다.
3. **어느 관찰이 가설을 살리거나 버리게 하는가.** 접촉·꼬리 침범·완료 종가·후속 수용을 구별하고, 가격 진전과 거래 참여가 일치하는지 본다. 장기 선의 유지와 지금 거래의 반응 실패, 별도 자본 제한을 분리한다. 횟수·큰 거래·지수 방향 하나로 확정하지 않는다.
4. **지금 살 것인가, 어디서 기다릴 것인가.** 현재 확인 진입 / 새 얕은 지지 / 깊은 재눌림 / 거절 중 실제 가능한 대안을 비교한다. 각각 진입 조건·유효기간·취소 이유·실패 가격/봉·가까운 공급·현재 위험을 적는다. 좋은 추세라도 현재 진입이 나쁠 수 있으며, 깊은 가격만 기다리면 추세를 놓칠 수 있다. 원래 planned RR과 현재 RR을 바꾸어 쓰지 않는다. 목표 누락을 무한 RR로 취급하지 않는다.
5. **얼마나 투입할 가치가 있는가.** 구조폭·체결/갭·유동성·비용을 감안한 전체 위험을 허용 범위와 대조한다. 다른 후보·현금 보유와 비교해 근거가 더 명확하고 자금 효율이 나은지 묻는다. 싼 원가나 계산상 좋은 RR만으로 우위를 주장하지 않는다. 비체결과 자금 점유 비용도 대가다.
6. **무엇을 보며 보유·추가할 것인가.** 높은 위치 수용과 새 연결부가 원 가설을 지지하면 단기 냉각만으로 종료하지 않는다. 새 기준은 처음 알 수 있게 된 뒤부터 쓴다. ADD는 새 물량의 진입 논거·상단 공간·추가 후 총위험이 모두 성립할 때의 별도 선택이다. 평단 낮추기나 일률적 배수만으로 승인·금지하지 않는다.
7. **상단에서 왜 일부 또는 전부를 팔 것인가.** 아래 표를 적용하되 실제 관찰로 하나를 선택한다. 경고가 애매하다고 자동 절반매도하지 않는다. 남긴 수량에도 현재부터의 위험과 종료 조건이 있다.
8. **실패 뒤 무엇이 달라져야 다시 살 것인가.** 종료 사유·손실·비용 장부를 보존한다. 단순 같은 가격 재접근이 아니라 회복/수용·새 구조·시장/유동성 등 원래 무효화 이유가 바뀌었는지 확인한다. 손실 뒤 시간축을 늘려 기존 실패를 없애지 않는다.

## 분석 한 건의 최소 출력

`자료시각/완료봉 → 거래 목적 → 원천이 있는 핵심 구조·근처 공급 → 현재 행동과 대안 거절 이유 → 조건/실패/취소 → 수량·총위험에 필요한 정보 → 보유/ADD/축소/전량 조건 → 생각을 바꿀 관찰 → 미확인·기회비용`

가격·수량·행동은 충분한 당시 자료가 있을 때만 구체화한다. 숫자가 없으면 이유와 필요한 자료를 명시하며, 모든 후보에 매수를 만들어내지 않는다. 행동 계획의 논리적 일관성과 실제로 수익을 내는 선택 능력은 따로 평가한다.
